# Prism 模块组织架构

目标是独立的轻量模块平台。集合、模块、入口、内容四层各有明确身份；脚本的数据源在宿主原生框架内展示，模块不拥有另一套应用导航。

```text
.prs 集合（分发目录）
  └─ .js 源码 / .prism 加密模块（安装与更新单位）
       ├─ PrismMetadata（身份、版本、声明、参数）
       ├─ modules[].id（列表、播放、字幕、弹幕入口）
       ├─ search（独立搜索入口）
       └─ loadDetail(link)（自有资源补全）

原生设置 → 参数解析 → 执行调度 → Prism API
                          ├─ 媒体与分区 → 资源库 / 详情 / 分集
                          ├─ 播放资源 → 版本选择 / 播放器
                          └─ 字幕 / 弹幕 → 现有播放控件
```

## 职责与边界

| 组件 | 职责 |
| --- | --- |
| PrismModuleModels | 协议类型、能力、参数与原生模型转换 |
| PrismModuleStore | 集合读取、声明验证、安装、更新、卸载 |
| PrismModuleCipher | 加密封装识别、版本检查、认证解密 |
| PrismModuleRuntime | JSContext、Prism API、函数调度与结果解析 |
| PrismModuleService | 后台执行、同模块串行、请求合并、内容缓存 |
| PrismModuleStorage | 私有状态与显式共享缓存 |
| PrismModuleLibrary / Views / Settings | 原生资源页、分页、参数与模块管理 |
| PrismModuleMedia / DanmakuSource | 字幕和弹幕接入 |
| 现有详情及播放器 | 选择作品、分集、版本、刷新地址并播放 |

不增加依赖容器、常驻进程、事件总线或第三方 UI 框架。JSContext 按调用创建；持久状态由宿主存储服务管理。

## 本轮对齐结果

| 检查项 | 处理 |
| --- | --- |
| 平台身份与运行 API | 统一为 PrismMetadata、Prism、协议 v1；新导入必须显式声明 |
| 集合与模块混淆 | .prs 仅做索引，.js/.prism 才是可安装模块 |
| 同函数多栏目 | 按入口 ID 选择参数和缓存，不按函数名猜分类 |
| 数据源与页面归属 | 资源、详情、分集保留模块与路由身份，分类回到原入口 |
| 媒体库接入 | 模块声明能力，用户单独开启；非 TMDB 内容不聚合 |
| 设置和更新 | 全局、栏目、搜索分作用域；更新保留选择，不自动打开接入 |
| 缓存 | 内容快照、脚本状态、共享缓存分层；密文模块不以明文落盘 |
| 播放 | 媒体与播放结果分开；临时地址在播放/切源时重新解析 |
| 身份和完整性 | 集合摘要、ID、版本及加密认证共同校验，失败不覆盖旧版本 |
| 测试归属 | 使用 Prism 自有示例与本地固定数据，测试不依赖外部模块项目 |

## 明确的实现范围

当前页面结构采用原生列表、海报、横向卡片和轮播四种布局。任意网页界面、自定义原生二进制、浏览器执行入口和远程私有平台服务不属于 v1。

纯 JS 计算没有强制抢占；运行时的取消能力主要作用于网络和等待任务。sharedCache 的命名空间是显式协作约定，不能存放凭据。代码加密保护分发形态及完整性，不等于作者认证或不可逆向保证。

这些边界属于平台本身的约定，不要求开发者复制其他客户端行为。第三方文档、示例、打包工具与 skill 都以本仓库的 Prism 契约为准。

## 开发资料的组织

[开发手册](protocol.md)保留协议速查，并按入门、声明、运行时、媒体、资源库、播放、分发和测试分章。每章区分数据契约、当前行为与未支持能力，避免开发者依赖自动猜测或字段容错。

配套示例包括离线媒体库、结构化数据源、字幕和分段弹幕；离线测试检查发送的请求、返回模型和跨步骤身份，使用错误副本验证断言有效。skill 保持简短入口，按任务读取这些完整参考与示例。
